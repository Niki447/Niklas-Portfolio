Projekt

Jarvis

Ein selbst entwickelter, lokal laufender KI-Assistent — komplett auf eigener Hardware, ohne Cloud-Abhängigkeit und ohne laufende Kosten pro Anfrage. Seit Juli 2026 in aktiver Entwicklung, mittlerweile über 1.200 Commits in strukturierten Feature-Branches.

Features

Was Jarvis kann

Council

Multi-Agent-Verifikation

Ein Generator-Kritiker-Richter-Loop aus mehreren lokalen Modellen prüft Antworten gegenseitig, bevor sie ausgegeben werden — mehr Verlässlichkeit durch Verifikation statt reiner Rohleistung.

Memory

Langzeitgedächtnis

Millionen eingebettete Einträge in einer Vektordatenbank, dazu ein kleiner, handkuratierter Kern an Kerninformationen — echtes Projekt- und Kontextgedächtnis statt Session-Amnesie.

Aegis

Selbstkorrektur

Erkennt eigene Fehler (per Owner-Veto oder KPI-Abgleich) und schlägt kontrollierte, stufenweise freigegebene Korrekturen vor — nie eine unbeaufsichtigte automatische Änderung.

UI

Eigene Desktop-Oberfläche

Echtzeit-Overlay ("Signal Chamber") mit Glassmorphism-Design, Live-Wissensgraph und vollständigem Hell-/Dunkel-Theming — komplett selbst entwickelt.

Tech-Stack

Womit Jarvis gebaut ist

Python (FastAPI), Ollama für lokales Modell-Serving, Qdrant & ChromaDB für Vektorspeicher, Neo4j als Wissensgraph, Redis als Event-Bus, eigenes Desktop-Overlay (HTML/CSS/JS via pywebview).
